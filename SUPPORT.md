# Support

This repository supports only the unofficial Plasma client and its packaging.
It is not a Proton customer-support channel.

## Report here

- crashes or incorrect behavior in the Plasma Control Center or resident agent;
- KRunner, System Settings, notification, shortcut, or tray integration issues;
- failures in the community D-Bus adapter;
- Fedora RPM installation or lifecycle problems caused by this package;
- regressions that occur only with this client and can be reproduced safely.

The in-app Report an Issue page previews a small allowlisted local diagnostic
report and copies exactly that preview only when requested. It does not collect
logs or submit to Proton. Include steps to reproduce and expected behavior;
review any pasted text before posting. Share logs only when requested and after
manual redaction. Never post credentials, account tokens, recovery codes,
private keys, server certificates, IP addresses, or unreviewed support bundles.

## Contact Proton directly

Use [Proton Support](https://proton.me/support/contact) for:

- account access, billing, subscriptions, or account recovery;
- service availability, server incidents, or abuse reports;
- official Proton applications and unmodified official packages;
- questions about Proton policy, branding, or endorsement.

## Security reports

Do not open a public issue for a suspected vulnerability. Follow the private
process in [the security policy](SECURITY.md). If a finding is exclusively in
an unmodified official Proton component, use Proton's
official [security response and bug-bounty process](https://proton.me/security/response-center)
instead.
